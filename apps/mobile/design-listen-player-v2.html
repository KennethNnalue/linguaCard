Segment Track — Key Innovation
The segment visualiser directly maps to the PlaybackScript stored in ListenStore. Each row is an AudioSegment. The segmentIndex signal drives the .playing / .played CSS classes with zero imperative DOM manipulation.
Bug fixes visible here
B-01 fixed Segments always play — script is pre-compiled, runner uses concatMap to guarantee serial playback.

B-03 fixed AudioService wraps TTS callbacks in NgZone.run() + 8s timeout — no more silent hangs.

B-06 fixed No rating UI on this screen whatsoever.
Mode switching mid-session
Tapping a different mode calls store.updateSettings({ playMode }). The store recompiles scripts for remaining (unplayed) cards. Cards already played are not recompiled. Current card finishes its existing script before switching.
Error state design
Retry re-emits the failed segment into the runner. Skip this card calls store.next() which advances the card cursor and plays the next card's first segment. The play button turns red to signal paused-due-to-error status.

Deep Dive Grammar Segment
The grammar tip is an AudioSegment of type 'grammar_tip' with lang: 'en'. It is only included by compileScript() when mode === 'deepDive' and card.grammarNote is non-empty. The orange pill is purely decorative — it renders the same text that was already spoken.
Session Complete — No SRS
Zero calls to sm2.service.ts. No rating modal. The summary shows passive listen stats only. The "Listen again" button calls store.start({ shuffle: true, sameQueue: true }) — it uses the already-loaded rawQueue without fetching again.

Store integration
Each option emits the relevant source enum: 'due', 'collection:id', 'all', 'struggling'. store.loadQueue(source) uses rxMethod with switchMap to cancel any pending load and fetch fresh cards from CardStore.
Collection sub-selection
Tapping the "A collection" row does not dismiss the sheet. Instead it expands an inline list of collections from CollectionStore. Tapping a collection sets the source and dismisses.
Architecture Summary
The core insight: replace scattered async with a single serial pipeline. Every bug traced back to uncontrolled concurrency or wrong layer placement.
// Before: fire-and-forget hell
audioService.speak(card.front).then(() => {
  if (mode === 'examples') {
    setTimeout(() => {
      audioService.speak(card.exampleSentence).then(() => {
        // Sometimes never fires — hangs here forever ☠
        this.currentIndex++;         // ← race with shuffle
      });
    }, 600);
  } else {
    this.currentIndex++;
  }
});

// After: serial concatMap state machine
segmentRunner$.pipe(
  concatMap(seg =>
    seg.type === 'silence'
      ? timer(seg.durationMs)
      : audioService.speak(seg.text, seg.lang, speed)   // NgZone-safe + timeout
  ),
).subscribe(() => store.advanceSegment());   // pure patchState — no races
