Step 1

Create a topic

Create the topic once. If its external ID already exists, choose a different ID or continue with the existing topic below.
Step 2

Add an episode

Select the draft topic, then create its first episode. Publication happens later after images, transcript, and audio are ready.
Transcript format: JSON

JSON is required because speakers, dialogue turns, translations, and vocabulary references remain unambiguous and can be validated before audio generation. Plain text loses those relationships; PDF adds extraction errors and is not accepted.

Enter only an optional title and word list, copy the prompt, and ask an AI to return the JSON. Save it as a .json file and upload it; LinguaCard handles vocabulary reuse, new vocabulary, and provider voices.
