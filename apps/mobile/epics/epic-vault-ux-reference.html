LC-200
📋 Planned
Overview
What we're fixing
The Vault is the highest-frequency screen in LinguaCard. These six UX issues cause friction every session. This reference documents the redesigned states and components.
⚠ Icon-only actions — no labels ⚠ Orphaned "My Collections" page ⚠ All / Collections toggle is ambiguous ⚠ No contextual card creation ⚠ Collections have no urgency signal ⚠ Filter chips have no count badges
✓ Contextual action bar (labelled) ✓ Tab rail (Words / Collections) ✓ Speed-dial FAB ✓ Urgency strips on collection cards ✓ Filter chips with count badges ✓ Collections as first-class tab

1
Contextual action bar. Primary action is labelled ("Add Card" or "New Collection") and adapts per tab. Import is demoted to a secondary labelled button, overflow in ⋯ menu.
2
Tab rail. Words and Collections are explicit tabs — always visible, always one tap away. Replaces the ambiguous toggle and retires the orphaned "My Collections" page.
3
Urgency strips. Red left border = >50% due. Amber = >20%. Progress bar and "% due" label give at-a-glance health. Stats banner replaces the old opaque green hero.
4
Filter chips with count badges. "Due 184" in red-tinted badge signals urgency without opening the view. "New 42" gives context on uncommitted words.
LC-204 · Component
Speed-dial FAB (expanded state)
The accent FAB expands on single tap into three labelled mini-actions. The backdrop blurs the list so the actions are clearly in focus. Dismisses on tap outside or on second tap of the FAB (which becomes an ✕).

LC-201 + LC-202 · Navigation
Retired flow vs. new flow
The orphaned "My Collections" page is retired. Back navigation from collection detail now returns to Vault?tab=collections, not a standalone page. The Collections tab is the canonical entry point.

Component Specifications
New & modified components
Token references, selector names, and key inputs for each new or modified component in this epic.
Component Story Location Key tokens / notes
Tab Rail LC-201 vault.page.html Active underline: --lc-brand, 2px. Font: 13px 600. Replaces toggle entirely.
Contextual Action Bar LC-203 vault.page.html header Primary: --lc-accent bg + shadow. Secondary: card bg + border. Overflow: 36×36 icon btn. Adapts based on active tab signal.
SpeedDialFabComponent LC-204 shared/components/speed-dial-fab/ FAB: --lc-accent 48px. Mini: card bg 36px. Labels: --lc-brand-dark bg, white text. Backdrop: 85% surface + blur(2px). Emits: actionSelected event with action enum.
CollectionCardComponent LC-205 vault/components/collection-card/ Urgency bar: 4px wide. Red ≥50% due, Amber ≥20%, transparent otherwise. Progress bar: --lc-mastery-4 fill, 4px height. dueRatio computed signal from CollectionStore.
Filter Chips (updated) LC-207 vault.page.html Count badge: inactive chips use --lc-accent-light + --lc-accent. "Due" badge with urgency count uses #FEF2F2 + #B91C1C. Active chip badge: rgba(255,255,255,0.25).
Overflow Menu LC-203 vault.page.html (inline sheet) Card bg, --lc-radius-md 12px, border + float shadow. Items: 12px 500, 11px icon. Dismiss on tap-outside via backdrop overlay.
Stats Banner LC-205 Inside Collections tab Brand dark bg. Three stat columns separated by 1px rgba dividers. "Due today" value in #FCD34D when count > 0. Decorative circle pseudos for depth.
Empty State (collections) LC-201 Collections tab, zero state Reuses <lc-empty-state>. Icon 📁, title "No collections yet", CTA "Create your first one" → triggers New Collection sheet.
