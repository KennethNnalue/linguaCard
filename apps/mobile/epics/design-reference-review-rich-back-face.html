New component signals & methods

expandedSynonyms
signal<Set<number>>(new Set())

toggleReviewSynonym(i)
copies Set, toggles index i, re-sets signal

isReviewSynonymExpanded(i)
returns expandedSynonyms().has(i)

effect() reset
reads currentIndex(); calls expandedSynonyms.set(new Set()) on advance

highlightWord(sentence, word)
regex replace → wraps in <strong>; safe escape; case-insensitive

⚠️ highlightWord() already exists for main examples — check before adding a duplicate. Reuse if present.
