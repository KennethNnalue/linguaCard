Rationale
Why each change was made
1. Text-tabs replace pill chips
Pill chips with colored count badges borrow the visual language of notification indicators — red circles with numbers trigger the same "unread count" anxiety as email badges. This is wrong for a learning tool. Filters should feel like calm navigation, not alerts. Text labels with an underline active state (borrowed from tab navigation patterns) are the standard in tools like Linear, Notion, and Things 3 — apps known for low-friction, high-clarity UI. The underline is the only colored element, keeping the toolbar visually quiet while clearly showing which filter is active.
2. Counts become parenthetical text, not badges
"Due (631)" reads as data. 631 reads as an alarm. Both convey the same number, but the emotional weight is completely different. The parenthetical format is informative without being anxiety-inducing.
3. Article legend removed entirely
Every word card already displays its der/die/das badge in the appropriate gender color. The legend row (● der Masc. ● die Fem. ● das Neut.) is tutorial information the user learns within the first 30 seconds and then never needs again. It consumes ~32px of prime vertical real estate on every single visit. Removing it pushes the first word card ~50px higher — a meaningful improvement on a 5.8" phone screen.
4. Context summary as a soft nudge
The line "631 need review · 555 never studied" uses the app's accent color for the numbers — warm, motivating, not alarming. It appears only on the "All" view (when the user hasn't filtered yet) and disappears once they activate a specific filter, because the filtered list itself communicates the scope. This prevents redundant information and keeps the UI adaptive.
Implementation
Angular component changes
All changes are in vault.page.html and vault.page.scss. No store changes needed — filter logic and computed signals already exist.
ElementActionImplementation detail
.v2-filter-row Replace Delete entire .v2-filter-row div + .v2-filter-chip buttons. Replace with .n-toolbar containing .n-filter buttons. Remove .v2-filter-count badge styles.
.v2-article-legend Delete Remove the entire .v2-article-legend div from template. Delete .v2-art-pill, .v2-art-dot, .v2-art-spacer, .v2-sort-btn styles from SCSS.
.n-toolbar Create Single flex row. Filters use [class.active]="masteryFilter() === 'all'" etc. Active state: font-weight:600 + ::after pseudo (2px --lc-brand underline). Sort button at margin-left:auto.
.n-context Create Conditional: @if (masteryFilter() === 'all'). Shows dueCount() + newCount() in accent color. Hidden when any filter is active.
Sort button Move Sort moves from deleted article legend row into the .n-toolbar row, using (click)="openSortSheet()" — same handler, new location.
Counts (inactive filters) Simplify Only show parenthetical counts on filters that have non-zero values. @if (dueCount() > 0) { ({{ dueCount() }}) }. "Mastered (0)" shows (0) to communicate progress gap; could hide with @if (masteredCount() > 0).
